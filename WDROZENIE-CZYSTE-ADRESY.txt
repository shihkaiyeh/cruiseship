CZYSTE ADRESY – INSTRUKCJA WDROŻENIA
====================================

na stronie. Nie zmienia bazy Neon, zapisanych opinii ani ustawień Rendera.

JAK WDROŻYĆ
===========

1. Upewnij się, że w VS Code nie masz własnych niezapisanych zmian.
2. Rozpakuj paczkę.
3. Skopiuj wszystkie pliki z paczki do głównego folderu projektu cruiseship.
4. Gdy Windows zapyta, zaakceptuj zastąpienie istniejących plików.
5. W Source Control zobaczysz kilkanaście zmodyfikowanych plików. To normalne:
   każda strona zawiera własne odnośniki i ścieżki do CSS/JavaScript.
6. Wykonaj commit o nazwie:

   Czyste adresy URL

7. Kliknij Sync Changes.
8. Poczekaj na zakończenie automatycznego wdrożenia w Renderze.
9. Przetestuj adresy z sekcji NOWE ADRESY.


WAŻNE
=====

- Nie zmieniaj niczego w Neon.
- Nie zmieniaj Environment Variables w Renderze.
- Paczka nie zawiera .git, node_modules, zdjęć ani sekretów.
- Jeżeli VS Code pokaże znaczniki konfliktu <<<<<<<, nie wybieraj żadnej opcji.
  Zatrzymaj się i wyślij mi zrzut ekranu.
